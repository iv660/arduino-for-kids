# Четырёхразрядный цифровой дисплей

В этом уроке научим Arduino показывать цифры на четырёхразрядном дисплее. На всех четырёх индикаторах по очереди появятся `0000`, `1111`, `2222` и так до `9999`, а затем всё начнётся заново. 🔢✨

## Что нам понадобится

- Arduino Leonardo;
- USB-кабель;
- компьютер с PlatformIO;
- четырёхразрядный дисплей с драйвером **TM1637**;
- 4 провода.

## Собери свою схему!

На дисплее есть четыре контакта: `CLK`, `DIO`, `VCC` и `GND`. TM1637 использует два сигнальных провода, но это не обычный I2C. Поэтому подключаем их к обычным цифровым пинам Arduino.

| Контакт дисплея | Куда подключить на Arduino Leonardo |
| --- | --- |
| `CLK` | пин **D8** |
| `DIO` | пин **D9** |
| `VCC` | **5V** |
| `GND` | **GND** |

Сначала отключи Arduino от USB. Подключи провода, ещё раз проверь названия контактов, а затем подключи USB. 🔌

## Библиотека для дисплея

Дисплеем будет управлять библиотека `TM1637Display`. Она уже указана в файле `platformio.ini`:

```ini
lib_deps =
    avishorp/TM1637Display
```

PlatformIO скачает библиотеку при первой сборке проекта.

## Класс `DigitalDisplay`

Библиотека умеет выполнять много разных команд. Чтобы главный код оставался простым, создадим класс-адаптер `DigitalDisplay`. Он будет понимать только одну полезную для нас команду: `showNumber()`.

```cpp
digitalDisplay.showNumber(currentDigit);
```

Эта команда покажет одну цифру сразу во всех четырёх разрядах.

## Цифры меняются от 0 до 9

### Что здесь происходит

Программа показывает текущую цифру, ждёт одну секунду и переходит к следующей. После цифры 9 она снова начинает с 0. Это похоже на табло лифта: на нём один за другим появляются номера этажей. ⏱️

### Как реализовать

#### Шаг 1: Напиши метод `DigitalDisplay.showNumber()`

Метод получает одну цифру. Умножь её на константу `repeatedDigitMultiplier`: тогда `3` превратится в `3333`, а `7` — в `7777`. Затем передай получившееся число библиотеке методом `showNumberDec()`.

Второй параметр `true` просит библиотеку показывать нули слева. Поэтому цифра 0 будет показана как `0000`, а не как пустой экран.

```cpp
void showNumber(int number) {
    int repeatedNumber = number * repeatedDigitMultiplier;
    display.showNumberDec(repeatedNumber, true);
}
```

#### Шаг 2: Напиши главный алгоритм в `loop()`

Замени комментарии `TODO` внутри `loop()` этим кодом:

```cpp
void loop() {
    digitalDisplay.showNumber(currentDigit);
    delay(displayInterval);

    currentDigit++;

    if (currentDigit > lastDigit) {
        currentDigit = firstDigit;
    }
}
```

Сначала показываем цифру. Потом ждём секунду. Затем увеличиваем цифру. Отдельная простая проверка возвращает счёт к 0 после 9.

## Запуск программы

1. Заполни метод `showNumber()` и функцию `loop()`.
2. Сохрани `src/main.cpp`.
3. Подключи Arduino к компьютеру через USB.
4. Открой терминал в папке `07. Digital Display` и введи:

```bash
platformio run --target upload
```

После загрузки на дисплее будут по очереди появляться `0000`, `1111`, `2222` и другие цифры до `9999`. 🎉

## Экспериментируй!

Измени константу `displayInterval` в начале программы:

```cpp
const unsigned long displayInterval = 1000;
```

- `const unsigned long displayInterval = 500;` — цифры будут меняться два раза в секунду;
- `const unsigned long displayInterval = 2000;` — каждая цифра будет видна две секунды.

## Словарик

- **Семисегментный индикатор** — индикатор из семи светящихся полосок, которые складываются в цифры.
- **Разряд** — одно место для цифры на дисплее. У этого дисплея четыре разряда.
- **TM1637** — драйвер на плате дисплея, который управляет индикаторами.
- **CLK** — провод, по которому Arduino задаёт ритм обмена с дисплеем.
- **DIO** — провод, по которому Arduino отправляет данные дисплею.
- **Класс-адаптер** — класс, который делает работу со сложной библиотекой проще.
- **Библиотека** — готовый код, которым можно пользоваться в своей программе.
- **`showNumber()`** — метод класса `DigitalDisplay`, который показывает цифру на дисплее.
- **`delay()`** — команда ожидания; число внутри указано в миллисекундах.
- **Миллисекунда** — одна тысячная секунды; 1000 миллисекунд — это 1 секунда.
